# 기능 목록 정리


## 입력
- [x] 로또 구입 금액을 1,000원 단위로 입력받는다.

- [x] 6개의 당첨 번호를 한 줄로 입력받는다. (ex. `"1,2,3,4,5,6"`)

- [x] 보너스 번호 한 개를 입력받는다.


## 출력
- [x] 프로그램 시작 시 구입 금액 입력 안내 메시지를 출력한다.

- [x] 발행한 로또 수량 및 번호를 형식에 맞춰 출력한다. (ex. `"[8, 21, 23, 41, 42, 43]"..`)

- [x] 당첨 내역을 형식에 맞춰 출력한다. (ex. `"3개 일치 (5,000원) - 1개"..`)

- [x] 수익률을 형식에 맞춰 출력한다. (ex. `"총 수익률은 62.5%입니다."`)


## 게임 진행
- [x] 1개의 로또를 발행할 때 6개의 숫자를 뽑는다.

- [x] 당첨은 1등부터 5등까지 있으며, 기준에 따른 금액이 있다.

- [x] 로또 구입 금액에 해당하는 만큼 로또를 발행한다.


## 도메인 규칙/검증
- [x] 로또/당첨/보너스 번호의 숫자 범위는 1~45까지이다.

- [x] 로또/당첨&보너스 번호는 중복되지 않는다.

- [x] 로또 번호는 오름차순으로 정렬하여 보여준다.

- [x] 당첨 번호는 쉼표(`,`)를 기준으로 구분 한다.

    - [x] 당첨 번호 입력 시 6개가 아닐 경우 예외 처리한다.

- [x] 로또 구입 금액이 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

- [x] 수익률은 둘째 자리에서 반올림한다. (ex. `100.0`, `51.5`, `1,000,000.0`)

- [ ] 에러 발생 시, `"[ERROR]"`로 시작하는 에러 메시지 출력 후 그 부분부터 재입력 받는다.


## 예외/엣지 케이스
- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException를 발생시킨다.

    - [ ] Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

- [ ] 숫자 외에 다른 값 입력 시 예외 처리한다. (구분자 제외)

- [ ] 입력이 빈 문자열(`""`)이거나 공백(`"   "`)만 있을 시 예외 처리한다.

- [x] 입력 앞뒤 공백, 또는 구분자(쉼표 등) 앞뒤의 공백은 제거 후 정상 처리한다.
(ex. `"  4"` → `"[4]"`, `"1, 2,3"` → `"[1, 2, 3]"`)

- [ ] 숫자 내부에 공백이 포함되면 예외 처리한다. (ex. `140 00`, `4 1`)
